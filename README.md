# セクター別テクニカル総合スコア（日本17業種＋主要指数）

TOPIX-17業種ごとに5つのテクニカル指標を −2〜+2 で採点し、重み付きで
−100〜+100 の総合スコアにまとめてヒートマップで表示するアプリです。

## 2つの使い方

| | Streamlit版（app.py） | HTML版（make_html.py） |
|---|---|---|
| 向いている用途 | PCで重みを変えながら分析 | スマホでサッと確認 |
| 起動 | start_windows.bat | make_html_windows.bat → report.html ができる |
| 重みの変更 | 画面のスライダー | indicators.py の DEFAULT_WEIGHTS |

## 起動方法（Streamlit版）

1. Python 3.10 以上をインストール
2. このフォルダでターミナルを開いて実行
   ```
   pip install -r requirements.txt
   streamlit run app.py
   ```
3. ブラウザが自動で開きます（開かなければ http://localhost:8501 ）

初回は約70銘柄の株価を取得するので数十秒かかります。データは1時間キャッシュされます。

## 画面

| タブ | 内容 |
|---|---|
| 今日のシグナル | セクター×指標のヒートマップ。総合スコア順に並ぶ |
| 総合スコアの推移 | セクター×日付のヒートマップ。赤→緑に変わったところが買いシグナルが強まったタイミング |
| セクター詳細 | ローソク足＋25/75日線、売買代金、MACD と、直近10日のスコア内訳 |

左のサイドバーで各指標の重みをスライダーで変えられます。

## 採点ルール（indicators.py）

| 指標 | +2 / +1 | −1 / −2 |
|---|---|---|
| サイコロジカル(12日) | 上昇日25%以下 / 33%以下 | 67%以上 / 75%以上 |
| 出来高（売買代金） | 20日平均の1.5倍 / 1.2倍以上で上昇 | 同じ条件で下落 |
| MACD | 3日以内のゴールデンクロス / ヒストグラム＋で拡大 | ヒストグラム−で拡大 / デッドクロス |
| ローソク足 | 陽の包み足・赤三兵 / ハンマー | 上ヒゲの長い線 / 陰の包み足・黒三兵 |
| 移動平均(25/75) | 25日線>75日線で上向き＋株価が25日線より上 / 25日線>75日線 | 逆の条件 |

逆張りと順張りの矛盾対策として、移動平均が ±2（強いトレンド）のときに
サイコロがトレンドと逆向きなら、サイコロの重みを半分にしています。

## HTML版をスマホで見る

### A. 手元で作って送る（すぐ試せる）
1. `make_html_windows.bat` をダブルクリック → `report.html` ができてブラウザで開く
2. スマホに送る場合は、iPhoneなら AirDrop か「ファイル」アプリ（iCloud Drive）、
   Android なら Google ドライブ経由で開く
   ※ 表示は1回作った時点のデータ。毎日見るなら B がおすすめ

### B. GitHubで毎日自動更新（スマホのブックマークから毎日見られる）
平日16:40頃に自動でデータを取り直し、決まったURLに公開します。無料です。
1. GitHub（github.com）でアカウントを作り、新しいリポジトリを **Public** で作る
   （Pages を無料で使うには Public が必要。URLを知っていれば誰でも見られる点に注意。
   中身は市場データの集計だけで、個人情報は含まれません）
2. このフォルダの中身（`.github` フォルダも含む）をそのリポジトリにアップロード
3. リポジトリの Settings → Pages → Source を **GitHub Actions** にする
4. Actions タブ → daily-report → Run workflow で初回を手動実行
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で見られる。スマホでブックマーク

## ヒートマップの見方

セルの色は点数（濃い緑 +2 〜 濃い赤 −2）、セルの文字は実際の数値です。

| 列 | 表示例 | 意味 |
|---|---|---|
| サイコロ | 8勝4敗 | 直近12日の上昇日・下落日（横ばいは「分」） |
| 出来高 | 1.62倍↑ | 売買代金の20日平均比と、当日の株価の向き |
| MACD | GC2日前 / +0.17%拡大 | 3日以内のクロス、それ以外はヒストグラム（株価比）と拡大・縮小 |
| ローソク足 | 陽の包み足 / 陰線-1.2% | 出たパターン名。無ければ陽線/陰線と実体の大きさ（始値比） |
| 移動平均 | 25>75↑ +3.6% | 25日線と75日線の位置、25日線の向き、株価の25日線乖離率 |

## 対象（sectors.py）

- **日本（TOPIX-17業種）**：業種別ETF（1617〜1633）。出来高は主要構成銘柄の売買代金合計で代用
- **主要指数**：日経平均（^N225）、TOPIX（TOPIX連動ETF 1306で代用）、NYダウ（^DJI）、
  ナスダック総合（^IXIC）、S&P500（^GSPC）、DAX（^GDAXI）、SENSEX（^BSESN）
  - 出来高が配信されない指数（DAX・SENSEXなどで起きやすい）は「データなし」と表示し、
    出来高を除いた4指標で総合スコアを計算します
  - 市場ごとに休日が違うので、名前の下の日付はその市場の最新取引日です

指数を増やしたいときは `INDICES` に1行追加するだけです（Yahoo Financeのコードを指定）。

## ローソク足の説明

- HTML版：ローソク足の欄（点線の下線）にPCはカーソルを当てる、スマホはタップすると説明が出ます。
  見出しの「?」は見方の基本。詳細タブのチャートは、触れた日の値段と説明を表示します
- Streamlit版：ヒートマップとチャートにカーソルを当てると表示。「ローソク足の見方」の欄に一覧もあります
- 説明文は `indicators.py` の `CANDLE_HELP` で編集できます

## ファイル構成

- `app.py` … Streamlit版の画面
- `make_html.py` / `report_template.html` … HTML版の作成スクリプトとページのひな形
- `data.py` … 株価データの取得（両方で共通）
- `.github/workflows/report.yml` … 毎日自動更新の設定
- `indicators.py` … 指標の計算と採点（しきい値はここで調整）
- `sectors.py` … 対象セクターと、出来高の代わりに使う構成銘柄（各3銘柄。自由に入れ替え可）
